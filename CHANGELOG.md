# Changelog

## 0.1.0-beta.1

- First version: sensors, binary sensors and status for a Green Cell UPS via the web API
  of the GC UPS App. Optional buttons (battery self-test, beeper toggle), off by default.
- Integration icon, example dashboard (EN/DE), language-independent entity IDs
  (`sensor.gc_ups_*`), one-click HACS and setup buttons in the README.
